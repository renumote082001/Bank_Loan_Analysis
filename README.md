

📊 Bank Loan Analysis | Data Analyst Portfolio Project
📌 Project Overview

This project focuses on analyzing bank loan data to understand lending performance, borrower behavior, and risk patterns. The objective is to build an end-to-end data analysis solution using SQL Server and Power BI, enabling data-driven decision-making for loan approvals and portfolio management.

🎯 Problem Statement

The goal of this project is to:

-Analyze loan applications, funded amounts, and repayments
-Identify good vs bad loans
-Track key KPIs and trends over time
-Build interactive dashboards for business insights
🛠️ Tools & Technologies
-MS SQL Server – Data storage, querying, and transformation
-SQL Server Management Studio (SSMS) – Query execution
-Power BI – Data visualization & dashboard creation
-Excel – Data preprocessing (if required)
⚙️ Project Workflow
🔹 Part 1: SQL (Data Preparation)
-Created database and tables in SQL Server
-Imported raw loan dataset
-Performed data cleaning and transformation
-Wrote SQL queries to analyze:
-Loan applications
-Funded amount
-Amount received
-Interest rates and DTI
-Used advanced SQL concepts:
-CTEs
Window functions (Partition)
Aggregations (GROUP BY, COUNT, DISTINCT)
🔹 Part 2: Power BI (Data Visualization)
-Connected Power BI to SQL Server
-Performed data modeling and relationships
-Used Power Query for transformation
-Created DAX measures for KPIs
-Built interactive dashboards
📊 Dashboards
📍 Dashboard 1: Summary

Key KPIs:

-Total Loan Applications (MTD & MoM)
-Total Funded Amount
-Total Amount Received
-Average Interest Rate
-Average Debt-to-Income Ratio (DTI)

Good vs Bad Loan Analysis:

-Good Loan % and count
-Bad Loan % and count
-Funded & received amounts by loan quality
📍 Dashboard 2: Overview

Visual Insights:

📈 Monthly Trends (Line Chart)
🗺️ Regional Analysis by State (Map)
🍩 Loan Term Distribution (Donut Chart)
📊 Employment Length Analysis (Bar Chart)
📊 Loan Purpose Breakdown
🌳 Home Ownership Analysis (Tree Map)
📍 Dashboard 3: Details
-Detailed grid view of loan data
Comprehensive insights into:
-Loan performance
-Borrower profiles
-Financial metrics
📈 Key Insights
-Borrowers with lower credit quality contribute more to bad loans
-Certain regions show higher loan application volumes
-Employment length impacts loan approval and repayment
-Loan purpose influences funding and repayment behavior
